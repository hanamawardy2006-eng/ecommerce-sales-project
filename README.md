# Ecommerce Business Analysis Project

تحتوي هذه الحزمة على ملفات مشروع تحليل أعمال للتجارة الإلكترونية.

## المحتويات

- `Ecommerce_Business_Analysis_EN (1).docx`: تقرير تحليل الأعمال باللغة الإنجليزية. يُفتح باستخدام Microsoft Word أو أي قارئ ملفات DOCX متوافق.
- `powerbi_finalproject.zip`: ملف مضغوط يحتوي على لوحة Power BI باسم `powerbi_finalproject.pbix`. فك ضغطه ثم افتح ملف PBIX بواسطة Microsoft Power BI Desktop.
- `project.ipynb 2.ipynb`: دفتر Jupyter Notebook للتحليل البرمجي. يمكن فتحه عبر Jupyter Notebook أو VS Code أو Google Colab.

## ملاحظات الاستخدام

1. لا تغيّر أسماء الملفات إذا كانت هناك روابط أو مراجع بينها في المشروع.
2. يُنصح باستخدام Power BI Desktop لعرض ملف لوحة المعلومات.
3. افتح ملف الـ Notebook في بيئة تحتوي على مكتبات Python المطلوبة إن ظهرت رسالة نقص مكتبات.
